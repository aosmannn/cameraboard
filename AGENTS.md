# Rules for any AI tool or contributor working in this repo

- Branch names: `adam/<topic>` or `steven/<topic>`. Never name a branch after a tool (no `cursor/`, `claude/`, `codex/`, etc.).
- Commits are authored by the person who asked for the work. No `Co-authored-by`, `Generated with`, or session-link lines naming a tool.
- Do not open pull requests or push to `main` unless asked. Deploys are done by Adam.
- No third-party map services, tiles or hosted 3D models. Everything on the map is bundled data or code.
- American spelling.
- Run `npm run build` (type check + build) before pushing.
